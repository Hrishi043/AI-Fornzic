# Project report source

`Project_Report.tex` is the editable LaTeX report source, prepared for the
Overleaf workflow specified in the supplied report-format PDF.

## Compile

1. Upload `Project_Report.tex` to a new Overleaf project.
2. Select pdfLaTeX as the compiler and compile. The source uses standard
   Overleaf packages, including `newtxtext`, `newtxmath`, `setspace`,
   `geometry`, and `hyperref`.
3. Replace the bracketed title-page fields with the student's and
   institution's information.
4. Review the generated contents, page breaks, bibliography, and tables
   before submission.

## Submission note

The supplied template states a minimum of 60 pages. This source is a
fact-grounded technical report draft, but it is not padded to claim that it
meets that minimum. Compile it to see the actual page count, then expand it
with approved project evidence where required: supervisor and institutional
front matter, original UI screenshots, complete implementation appendices,
additional documented tests, and any required institutional chapters.
Do not expand the report by inventing experiments, results, requirements, or
references.
